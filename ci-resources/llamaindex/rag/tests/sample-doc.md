# Zephyrion Cloud Storage - Internal Retention Policy

Zephyrion is a fictional internal archival storage system used only for
testing this RAG pipeline. It does not exist anywhere else, so a correct
answer can only come from retrieving this document, not from a model's
pretraining knowledge.

The maximum retention period for archived snapshots in the Zephyrion Cloud
Storage system is 47 days. After 47 days, archived snapshots are permanently
and irreversibly deleted. This limit applies to all snapshot tiers, including
the "cold-vault" tier.
